# quran-app

## Saved data

The app stores bookmarks, notes, and your last-read position in browser storage.
This lets those features work on the static GitHub Pages deployment without a
separate server. Saved data is private to the browser and site origin where it
was created; it is not synchronized across devices and may be removed if browser
site data is cleared.

Open `index.html` with Live Server or visit the deployed app at
https://waleedabdi.github.io/quran-app/.
