# Noor Reader

Noor Reader is a website for reading the Quran. You can read it, listen to it, and save your favorite parts.

## Project Objectives

-To make reading the Quran easier.
-To allow users to listen to Quran recitations.
-To help users save their favorite verses.-
-To provide a simple and user-friendly experience.

## Technologies Used

 -HTML 
 -CSS 
 -JavaScript 
 -Al Quran Cloud API 
 -json-server 
 -Jest 
 -Figma
